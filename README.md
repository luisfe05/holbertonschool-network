# holbertonschool-network

## Description
Networking projects from Holberton School: fundamentals, host configuration and how the web works.

## Projects

| Directory | Description |
| :--- | :--- |
| **`basics_0`** | OSI model, network types, MAC/IP addresses, TCP vs UDP, ports and `ping`. |
| **`basics_1`** | `/etc/hosts`, listing IPv4 addresses and listening on a port with `nc`. |
| **`what_happens_when_your_type_google_com_in_your_browser_and_press_enter`** | Blog post and diagram explaining the full flow of a request to `https://www.google.com`. |
