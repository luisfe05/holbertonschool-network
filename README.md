# Network Basics 0

Este proyecto introduce conceptos fundamentales de redes informáticas, incluyendo el modelo OSI, tipos de redes (LAN, WAN, Internet), direcciones MAC e IP, protocolos de transporte (TCP y UDP), puertos comunes y herramientas básicas de diagnóstico en Bash.

## Archivos y Tareas

- `0-OSI_model`: Respuestas sobre el modelo conceptual OSI y su organización por capas.
- `1-types_of_network`: Respuestas sobre clasificación de redes (LAN, WAN, Internet).
- `2-MAC_and_IP_address`: Respuestas sobre direcciones físicas MAC y direccionamiento lógico IP.
- `3-UDP_and_TCP`: Respuestas comparativas entre las características y funcionamiento de TCP y UDP.
- `4-TCP_and_UDP_ports`: Script Bash que muestra los puertos en escucha y los procesos correspondientes.
- `5-is_the_host_on_the_network`: Script Bash que verifica la disponibilidad de un host enviando 5 paquetes ICMP echo (ping).
